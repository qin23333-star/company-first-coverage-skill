# Full Report Quality Gate

只有以下强制项全部通过，才能结束完整首次覆盖任务。

## 1. Access and Materials

- [ ] 已确认公司、代码、交易所、报告基准日、资料目录和输出位置。
- [ ] 已递归审计全部高相关本地资料。
- [ ] 内部资料矩阵不存在未处理的高相关文件。
- [ ] 联网可用时已完成全球公开来源审计；不可用时已明确限制。

## 2. Structure and Depth

- [ ] 正文不是提纲、公司简介或聊天摘要。
- [ ] 默认章节已完整覆盖；条件章节缺资料时保留缺口说明。
- [ ] 完整模式通常达到约 15,000—25,000 个中文字符；约 40 页版本通常规划为 18,000—30,000 个中文字符。
- [ ] 字数不足时，原因是证据确实不足，而不是单次输出截断、资料漏读或提前停止。
- [ ] 没有通过重复结论、堆来源或放大表格凑篇幅。

## 3. Research Logic

- [ ] 使用“第一性原理”并完成从真实问题到财务兑现的因果链。
- [ ] 判断行业生命周期、公司全球链条位置和利润池归属。
- [ ] 需求、订单/代理指标、供给、收入、毛利率和现金流相互验证。
- [ ] 比较主要竞品的产品、价格、性能、交付、生态和客户认可。
- [ ] 明确正面证据、反面证据、待确认项和证伪条件。

## 4. Evidence and Finance

- [ ] 关键结论有一手证据或多个独立二手证据。
- [ ] 事实、观点、推演和待确认假设已经分层。
- [ ] 图表、数字和引文可追溯到具体来源、日期和口径。
- [ ] 历史财务与公告勾稽，单位、币种和期间一致。
- [ ] 财务预测和估值资料距写作日不超过 6 个月；否则明确缺口。
- [ ] 没有目标价、投资评级、仓位或具体买卖建议。

## 5. Visuals and Files

- [ ] 完整模式通常包含 5—8 个高价值视觉。
- [ ] 至少覆盖营收拆分、需求/兑现流程、产业位置和量化趋势四类；无法完成的类别有证据缺口说明。
- [ ] 图片链接存在，中文、单位、图例、来源和宽度清晰。
- [ ] 报告与图片使用可移植相对路径，没有创建者个人绝对路径。

## 6. Final Stop Check

在提交前执行一次反向检查：

1. 从资料文件夹回看报告，确认没有漏掉高相关资料。
2. 从每个核心结论回看来源，确认事实强度没有被夸大。
3. 从每张图回看正文，确认它回答独立投资问题而非装饰。
4. 从风险和跟踪清单回看核心逻辑，确认存在可观察的修正条件。
5. 如果任何强制项未通过，继续研究或写作；不要以“已生成若干页”作为完成依据。
