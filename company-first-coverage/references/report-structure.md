# Report Structure and Analysis Framework

## Contents

1. Default structure
2. Opening and business boundary
3. First-principles and lifecycle analysis
4. Orders and realization
5. Competition and global value chain
6. Company capabilities
7. Chapter ownership

## 1. Default Structure

正文第一行直接从开篇小结开始，不另写封面元信息。

```markdown
# 开篇小结：怎么看这家公司

# 公司基本情况与业务边界

# 第一性原理：行业为什么成立

# 行业生命周期与需求传导

# 发展阶段与竞争格局

# 行业核心能力

# 公司掌握情况与验证证据

# 行业地位与供应链位置

# 公司治理、发展历史与关键人物

# 订单、供给能力与兑现节奏

# 财务质量

# 财务预测

# 估值

# 核心结论

# 风险提示

# 行业基础知识与概念解释

# 资料来源
```

财务预测和估值是条件章节。缺少近 6 个月合格资料时保留标题并明确数据缺口，不得自行补数。

## 2. Opening and Business Boundary

开篇小结约 100—200 个汉字，用一至两段说明：行业解决什么问题、公司卖什么、位于产业链哪里、最重要的优势/矛盾和最大待确认项。不要写成买卖建议。

“公司基本情况与业务边界”先放最新完整财年的业务结构图，优先同时呈现按产品/业务和按区域的收入拆分；图后再用短段回答“公司是什么、靠什么收费”。

## 3. First-Principles and Lifecycle Analysis

必须使用“第一性原理”，回答：

- 行业解决什么真实问题，客户为什么现在必须买。
- 旧方案为什么不够，决定性能、成本和可靠性的指标是什么。
- 稀缺瓶颈位于哪里，会体现为订单、交期、价格、认证还是毛利率。
- 客户 ROI 如何从产品能力传导到采购、收入、利润和现金流。

行业生命周期先用行业级定量数据判断总量、结构渗透和周期位置，再讨论公司受益。公司收入、型号发布时间或管理层历史不能代替行业数据。

半导体和硬件公司优先寻找总市场收入/出货、细分应用增速、库存/交期/供货年限等同口径序列。历史与预测必须视觉区分。

对于创新药，生命周期需拆成四层：行业技术路线阶段、单药从靶点发现到批准/商业化的阶段、公司管线组合的产品接力阶段，以及从批准到准入、处方、收入、毛利和现金流的兑现阶段。患者池属于需求侧，应与生命周期并列映射，而不是把患者总数当成生命周期指标。

肿瘤药必须建立“癌种—地区—治疗线—生物标志物—可及性”的患者漏斗：癌种年度新发或进展患者 → 确诊 → 符合分型/靶点 → 进入适用治疗线 → 获批地区可及且可支付 → 实际接受治疗。优先使用年度流量或同口径存量，明确统计期间、地区、分母和来源；不同适应症或管线存在患者重叠时不得简单相加。患者池不足时保留“待补/待确认”，不能用癌种总患者数直接推出 TAM、销售峰值或估值。

## 4. Orders and Realization

按商业模式选择最接近收入实现的验证指标：

- 设备/制造：在手订单、采购、认证、产能、稼动率、良率、交期、验收、收入确认。
- 芯片设计：流片、晶圆/封测、平台认证、客户导入、拉货、库存、量产、毛利率。
- AI 模型/软件：ARR、付费客户、调用量、留存/复购、算力、单位成本、毛利率和现金消耗。

订单同时验证需求、供给和竞争格局。没有直接订单时使用有效代理指标并说明边界；没有有效代理指标时写“待确认：需求判断缺乏订单验证”。

## 5. Competition and Global Value Chain

用比较表回答谁更好、好在哪里、客户是否认可，以及价格、性能、交付、生态、稳定性和服务差异。只有对未来收入、利润或估值影响显著的技术变量才深入原理。

判断全球利润池在哪里，公司是核心链条、Tier 1、Tier 2/3、本土映射还是主题资产。回答客户为什么必须用它，以及行业增长后利润留在公司、客户、上游、云厂商、渠道还是海外龙头。

份额口径缺失时，不制作分母不清的市场份额饼图。选择 3—4 家产品重合度、商业模式和客户场景相近的同行，使用同一报告期的营收、增速、归母净利润和净利率做“同行经营位置”，不得称为市场份额。

## 6. Company Capabilities

研究过程中可以拆解研发、工程化、产能、良率、交付、渠道、生态、专利、成本、认证和服务网络；正文中的“行业核心能力”和“公司掌握情况”默认归并为三项：

- 销售渠道：客户覆盖、直销/经销、方案商、导入、认证、交付和售后。
- 品牌：市场地位、标杆案例、可靠性口碑、全球覆盖、平台信任和定价能力。
- 研发：产品定义、研发组织、核心 IP、技术路线、工程化、工具链、质量和工艺。

同一能力只在最能解释竞争优势的一类完整展开，其他位置引用结论。

## 7. Chapter Ownership

- 行业生命周期：行业需求、供需和传导链；创新药可在本章增加单药生命周期、管线组合接力和全球患者池映射，但不混入公司订单或管理层历史。患者池只作为需求分母，不能替代订单、处方或收入证据。
- 发展阶段与竞争格局：商业化进度、主要路线和竞争状态。
- 行业核心能力：任何赢家必须具备什么。
- 公司掌握情况：本公司实际做到了什么、证据是什么。
- 行业地位与供应链位置：份额、客户层级、全球位置和利润池。
- 公司治理：股权、管理层、组织执行和关键节点。
- 订单与兑现：公司层面的订单、采购、认证、交付、收入和利润证据。
- 核心结论：估值之后、风险之前，集中归纳已成立事实、待验证边界和估值状态。
- 风险提示：承接强化、削弱、证伪信号和下一次更新触发点。

同一信息只在一个章节完整展开，其他章节引用结论，避免重复堆砌。
